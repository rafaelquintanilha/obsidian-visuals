# Style Profiles

Style profiles are reusable preferences for visual direction. They are not hard constraints; adapt them to the note.

## essays

Use for literary, reflective, Substack-style essays.

- default job: `cover`
- default aspect ratio: `16:9`
- default text policy: `no-rendered-text`
- tone: restrained, editorial, literary, symbolic
- composition: spacious, magazine-like, one strong focal metaphor
- color: muted, high contrast, warm paper tones or deep shadows
- avoid:
  - generic AI glow
  - glossy startup gradients
  - horror cliches
  - fake book covers
  - AI-rendered text
  - literal devils unless explicitly requested

## technical-explainer

Use for systems, workflows, tools, and conceptual diagrams.

- default job: `explainer`
- default aspect ratio: `16:9`
- default text policy: `text-safe`
- tone: precise, structured, calm
- composition: clear relationship between concepts, not decorative
- avoid:
  - dense unreadable text
  - generic network blobs
  - fake UI screenshots unless useful

## quote-card

Use for a visual built around a passage.

- default job: `quote-card`
- default aspect ratio: `4:5` unless the user asks otherwise
- default text policy: `text-safe`
- tone: editorial, high-legibility, restrained
- avoid:
  - long AI-rendered quotes
  - decorative clutter
